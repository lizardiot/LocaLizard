# Changelog

Все заметные изменения проекта LocaLizard фиксируются здесь.

## [0.0.1.8] — 2026-10-29

### Изменено
- Проект и приложение переименованы в **LocaLizard**.
- Исполняемый файл переименован в `LocaLizard.exe`.
- Версия в приложении и релизе синхронизирована до `0.0.1.8`.
- Релиз содержит README, CHANGELOG и контрольную сумму SHA-256.
- Автоматическая публикация очищает старые GitHub Releases и теги перед созданием единственного релиза `0.0.1.8`.

### Реализовано
- Windows GUI для выбора исходного и итогового ISO.
- Проверка свободного места, журналирование и JSON-отчёт.
- Работа с установочными WIM/ESD и статические проверки структуры готового ISO.
- Поиск пакетов ru-RU через UUP Dump API с проверками доступных метаданных и ограничением доменов загрузки.
- CI-сборка самостоятельного Windows x64 EXE на GitHub Actions.

### Известные ограничения
- Полная русификация всех языковых возможностей Windows не гарантируется.
- Доступность языкового пакета и FOD зависит от сборки и архитектуры Windows.
- WinRE не модифицируется; Setup/WinPE локализуется только при наличии подходящих пакетов.
- Автоматическая проверка загрузки ISO в виртуальной машине не выполняется.
- Требуется практическая проверка на копии целевого ISO перед повседневным использованием.
