# Changelog

## [0.0.9.0] — 2026-10-29

### Добавлено
- Microsoft Update Catalog: поиск конкретного KB или автопоиск стабильного LCU по семейству сборки и архитектуре выбранного ISO.
- Выбор записи Catalog и подтверждение перед загрузкой; фильтрация Preview/Insider/Canary, Server и другой архитектуры.
- Загрузка связанных checkpoint MSU и target LCU по HTTPS с доменов Microsoft; проверка Catalog SHA-1, когда digest опубликован; вычисление SHA-256 и создание updates.json, catalog-source.json и SHA256.txt.
- Интерактивная Hyper-V boot-проверка: пользователь подтверждает видимость Windows Setup в VMConnect; результат записывается в аудит, VM запускается без сети и затем удаляется.
- Регрессионные тесты парсинга Catalog, фильтрации Preview/архитектуры, URL allowlist и профиля семейства сборки.

### Ограничения
- Автопоиск LCU включён для известных профилей сборок; нестандартные и старые версии требуют ручного KB.
- При изменении HTML Catalog или неоднозначном списке пакетов программа не угадывает пакет, а останавливается с ошибкой.
- Hyper-V тест требует визуального подтверждения оператора; реальная VM не запускается в CI.


Все заметные изменения проекта LocaLizard фиксируются здесь.


## [0.0.8.9] — 2026-10-29

Релиз собран в GitHub Actions для Windows x64; публикация выполняется только после успешного тестирования и сборки.

### Добавлено
- Локализация Windows Setup boot.wim index 2 и WinPE boot.wim index 1 при наличии подходящих ru-RU CAB и WinPE Add-on для целевой архитектуры.
- Проверка подписи установщика WinPE Add-on, копирование Setup resources из донорского ISO при совпадении build family/архитектуры, создание lang.ini и установка Setup UI ru-RU.
- Обработка вложенного WinRE из Windows-образа с ресурсами Language and Optional Features ISO.
- Update-chain manifest updates.json с SHA-256, build/architecture, checkpoint MSU и последним target LCU; target LCU повторно применяется после языкового пакета. Для WinRE поддерживаются отдельные типы winre_ssu и safeos_dynamic_update.
- Импорт split-WIM SWM в рабочий WIM; опциональное разделение итогового install.wim на SWM-части по 3800 MiB.
- Режим обработки существующего WIM в новый файл и опциональный Hyper-V smoke-test без сети с автоматической очисткой временной VM.

### Ограничения
- Автоматическое обнаружение/скачивание update chain из Microsoft Update Catalog не включено. Используется явно выбранный update-каталог с обновлениями и SHA-256-манифестом.
- Hyper-V smoke-test подтверждает запуск VM в течение 120 секунд, но не распознаёт экран Setup; требуется визуальная проверка.
- WinRE локализуется только при наличии подходящих ресурсов L&O ISO.

## [0.0.8.1] — 2026-10-29

### Улучшено
- Числовая сортировка версий UUP; отказ от архитектурного fallback к x64; фильтрация стабильных кандидатов по архитектуре и ветке.
- Повтор запросов UUP при HTTP 429/5xx, загрузка с ограниченными повторами и Range-resume, повторная проверка конечного URL после redirect.
- Манифест автоматического кэша с размером, SHA-1/SHA-256; повреждённые или неманифестированные файлы управляемого кэша не принимаются.
- Повторный кандидат Client Language Pack при отказе DISM; FOD capabilities устанавливаются через Add-Capability без установки произвольного CAB как fallback.
- Выбор ISO Language and Optional Features, сохранение GUI-путей, кнопки плана и проверки сети/источников, дополнительный localization audit JSON.
- Предварительная проверка ISO/места перед ADK; Authenticode установщика ADK проверяется до тихой установки.
- Setup language-pack directory выбирается с учётом архитектуры цели; обычный sources/langpacks/ru-ru/lp.cab не используется как WinPE пакет.
- Обычный push в main запускает тесты/сборку, но не переиздаёт прежний release tag.

### Ограничения
- WinPE index 1 и WinRE не изменяются; в Setup локализуется только index 2.
- Автоматические checkpoint CU/LCU, patch-existing-WIM, split SWM и boot-test VM остаются будущими задачами и не заявляются как реализованные.
- OOBE может влиять на preferred UI первого пользователя.

## [0.0.2.0] — 2026-10-29

### Добавлено
- Дополнительное поле «Русский ISO-источник»: программа может проверить второй Windows ISO, например ru-RU Windows 11 Enterprise LTSC 2024, когда UUP Dump недоступен.
- Поиск и локальное копирование распознаваемых standalone CAB для клиентского Language Pack, FOD и Setup/WinPE из совместимого по ветке сборки и архитектуре ISO.
- Русские Setup CAB из ISO могут использоваться как резервный источник при локализации Setup/WinPE, если набор компонентов полный.

### Безопасность и ограничения
- Целевой и дополнительный ISO проверяются отдельно; исходники не изменяются, а образ из дополнительного ISO не подменяет целевой IoT-образ.
- В качестве клиентского базового пакета не принимается общий `sources\\langpacks\\ru-ru\\lp.cab`: это может быть ресурс Setup, а не Client Language Pack.
- Если русский язык встроен только в `install.wim`/`install.esd`, программа сообщает, что самостоятельный CAB не найден, и пробует UUP Dump. Извлечение полноценного Client Language Pack из локализованного WIM автоматически не имитируется.
- Совместимость кандидатов всё равно проверяется DISM; точная применимость пакета, полный набор FOD, WinRE и успешная загрузка ISO в VM этим выпуском не гарантируются.
- Предыдущие релизы и теги сохранены.

## [0.0.1.9] — 2026-10-29

### Изменено
- Поиск русского базового языкового пакета больше не требует буквального совпадения названия SKU (IoT/Enterprise/Pro/Education) в имени CAB.
- Допускаются клиентские Language Pack CAB с распространёнными вариантами имени, если совпадают язык и архитектура; окончательную применимость конкретного пакета подтверждает DISM.
- Диагностика ошибки теперь объясняет, что отказ не связан только с названием редакции.
- GitHub Actions публикует версию `0.0.1.9` отдельным тегом и **сохраняет прежние релизы и теги**.
- К каждому релизу прикладываются `LocaLizard.exe`, `README.md`, `CHANGELOG.md` и `SHA256.txt`.

### Безопасные ограничения поиска
- Не допускаются серверные, WinPE, Setup, Recovery, FOD и Local Experience Pack CAB в качестве базового клиентского LP.
- Совпадения одного только языка недостаточно: должны совпадать архитектура и подходящая ветка ОС; применение проходит через DISM, который остаётся решающей проверкой совместимости.

### Прочее
- Номер версии приложения синхронизирован с релизом `0.0.1.9`.
- Сохранены предыдущие релизы, включая `0.0.1.8`.

## [0.0.1.8] — 2026-10-29

### Изменено
- Проект и приложение переименованы в **LocaLizard**.
- Исполняемый файл переименован в `LocaLizard.exe`.
- Релиз содержит README, CHANGELOG и контрольную сумму SHA-256.

### Реализовано
- Windows GUI для выбора исходного и итогового ISO.
- Проверка свободного места, журналирование и JSON-отчёт.
- Работа с установочными WIM/ESD и статические проверки структуры готового ISO.
- Поиск пакетов ru-RU через UUP Dump API с проверками доступных метаданных и ограничением доменов загрузки.
- CI-сборка самостоятельного Windows x64 EXE на GitHub Actions.

### Известные ограничения
- Полная русификация всех языковых возможностей Windows не гарантируется.
- Доступность FOD зависит от сборки и архитектуры Windows.
- WinRE не модифицируется; Setup/WinPE локализуется только при наличии подходящих пакетов.
- Автоматическая проверка загрузки ISO в виртуальной машине не выполняется.
