# Changelog

Все заметные изменения проекта LocaLizard фиксируются здесь.

## [0.0.2.0] — 2026-10-29

### Добавлено
- Дополнительное поле «Русский ISO-источник»: программа может проверить второй Windows ISO, например ru-RU Windows 11 Enterprise LTSC 2024, когда UUP Dump недоступен.
- Поиск и локальное копирование распознаваемых standalone CAB для клиентского Language Pack, FOD и Setup/WinPE из совместимого по ветке сборки и архитектуре ISO.
- Русские Setup CAB из ISO могут использоваться как резервный источник при локализации Setup/WinPE, если набор компонентов полный.

### Безопасность и ограничения
- Целевой и дополнительный ISO проверяются отдельно; исходники не изменяются, а образ из дополнительного ISO не подменяет целевой IoT-образ.
- В качестве клиентского базового пакета не принимается общий `sources\\langpacks\\ru-ru\\lp.cab`: это может быть ресурс Setup, а не Client Language Pack.
- Если русский язык встроен только в `install.wim`/`install.esd`, программа сообщает, что самостоятельный CAB не найден, и пробует UUP Dump. Извлечение полноценного Client Language Pack из локализованного WIM автоматически не имитируется.
- Совместимость кандидатов всё равно проверяется DISM; точная применимость пакета, полный набор FOD, WinRE и успешная загрузка ISO в VM этим выпуском не гарантируются.
- Предыдущие релизы и теги сохранены.

## [0.0.1.9] — 2026-10-29

### Изменено
- Поиск русского базового языкового пакета больше не требует буквального совпадения названия SKU (IoT/Enterprise/Pro/Education) в имени CAB.
- Допускаются клиентские Language Pack CAB с распространёнными вариантами имени, если совпадают язык и архитектура; окончательную применимость конкретного пакета подтверждает DISM.
- Диагностика ошибки теперь объясняет, что отказ не связан только с названием редакции.
- GitHub Actions публикует версию `0.0.1.9` отдельным тегом и **сохраняет прежние релизы и теги**.
- К каждому релизу прикладываются `LocaLizard.exe`, `README.md`, `CHANGELOG.md` и `SHA256.txt`.

### Безопасные ограничения поиска
- Не допускаются серверные, WinPE, Setup, Recovery, FOD и Local Experience Pack CAB в качестве базового клиентского LP.
- Совпадения одного только языка недостаточно: должны совпадать архитектура и подходящая ветка ОС; применение проходит через DISM, который остаётся решающей проверкой совместимости.

### Прочее
- Номер версии приложения синхронизирован с релизом `0.0.1.9`.
- Сохранены предыдущие релизы, включая `0.0.1.8`.

## [0.0.1.8] — 2026-10-29

### Изменено
- Проект и приложение переименованы в **LocaLizard**.
- Исполняемый файл переименован в `LocaLizard.exe`.
- Релиз содержит README, CHANGELOG и контрольную сумму SHA-256.

### Реализовано
- Windows GUI для выбора исходного и итогового ISO.
- Проверка свободного места, журналирование и JSON-отчёт.
- Работа с установочными WIM/ESD и статические проверки структуры готового ISO.
- Поиск пакетов ru-RU через UUP Dump API с проверками доступных метаданных и ограничением доменов загрузки.
- CI-сборка самостоятельного Windows x64 EXE на GitHub Actions.

### Известные ограничения
- Полная русификация всех языковых возможностей Windows не гарантируется.
- Доступность FOD зависит от сборки и архитектуры Windows.
- WinRE не модифицируется; Setup/WinPE локализуется только при наличии подходящих пакетов.
- Автоматическая проверка загрузки ISO в виртуальной машине не выполняется.
