## [0.1.1] — 2026-10-30

### Исправлено

- Обработка вложенного WinRE из Windows-образа с ресурсами Language and Optional Features ISO.
- Update-chain manifest updates.json с SHA-256, build/architecture, checkpoint MSU и последним target LCU; target LCU повторно применяется после языкового пакета. Для WinRE поддерживаются отдельные типы winre_ssu и safeos_dynamic_update.
- Импорт split-WIM SWM в рабочий WIM; опциональное разделение итогового install.wim на SWM-части по 3800 MiB.
- Режим обработки существующего WIM в новый файл и опциональный Hyper-V smoke-test без сети с автоматической очисткой временной VM.

### Ограничения
- Автоматическое обнаружение/скачивание update chain из Microsoft Update Catalog не включено. Используется явно выбранный update-каталог с обновлениями и SHA-256-манифестом.
- Hyper-V smoke-test подтверждает запуск VM в течение 120 секунд, но не распознаёт экран Setup; требуется визуальная проверка.
- WinRE локализуется только при наличии подходящих ресурсов L&O ISO.

## [0.0.2] — 2026-10-29

### Добавлено
- Дополнительное поле «Русский ISO-источник»: программа может проверить второй Windows ISO, например ru-RU Windows 11 Enterprise LTSC 2024, когда UUP Dump недоступен.
- Поиск и локальное копирование распознаваемых standalone CAB для клиентского Language Pack, FOD и Setup/WinPE из совместимого по ветке сборки и архитектуре ISO.
- Русские Setup CAB из ISO могут использоваться как резервный источник при локализации Setup/WinPE, если набор компонентов полный.

### Безопасность и ограничения
- Целевой и дополнительный ISO проверяются отдельно; исходники не изменяются, а образ из дополнительного ISO не подменяет целевой IoT-образ.
- В качестве клиентского базового пакета не принимается общий `sources\\langpacks\\ru-ru\\lp.cab`: это может быть ресурс Setup, а не Client Language Pack.
- Если русский язык встроен только в `install.wim`/`install.esd`, программа сообщает, что самостоятельный CAB не найден, и пробует UUP Dump. Извлечение полноценного Client Language Pack из локализованного WIM автоматически не имитируется.
- Совместимость кандидатов всё равно проверяется DISM; точная применимость пакета, полный набор FOD, WinRE и успешная загрузка ISO в VM этим выпуском не гарантируются.
- Предыдущие релизы и теги сохранены.
