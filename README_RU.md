# IoT LTSC Russianizer

Графическая утилита для подготовки русифицированного ISO Windows IoT Enterprise LTSC.

## Скачать
Готовый Windows x64 EXE публикуется в разделе **Releases** после успешной сборки GitHub Actions. Сборка автоматическая; локально устанавливать Python или PyInstaller не требуется.

## Использование
1. Запустить `IoT_LTSC_Russianizer.exe`.
2. При запросе UAC подтвердить права администратора.
3. Выбрать входной ISO, итоговый ISO и рабочую папку.
4. Нажать «Проверить условия и создать ISO».

Приложение не изменяет исходный ISO. Перед обработкой рассчитывает требуемое свободное место, сохраняет журнал и выполняет статические проверки итогового ISO. Виртуальная машина не запускается.

## Автоматические зависимости
Приложение использует встроенные в Windows DISM, PowerShell и Robocopy. Если `oscdimg.exe` не обнаружен, приложение скачивает установщик Windows ADK с Microsoft и устанавливает Deployment Tools без отдельного ручного запуска. Языковые CAB оно ищет через UUP Dump API, а загруженные файлы принимает только при наличии прямого URL на домене Microsoft/Windows Update и проверке доступных метаданных.

## Ограничения
Это ранняя сборка. UUP Dump может не иметь подходящего Client Language Pack для конкретного старого IoT LTSC ISO, а набор дополнительных FOD-компонентов не гарантируется. В таком случае программа должна остановиться и сохранить журнал, а не утверждать, что русификация полная. WinRE в этой версии не редактируется. Setup/WinPE зависит от наличия соответствующих пакетов ADK. Совместимость конечного ISO с BIOS/UEFI проверяется статически, без виртуальной машины.

Не запускайте установку с критически важного носителя без отдельной проверки полученного ISO.
