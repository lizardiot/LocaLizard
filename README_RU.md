# LocaLizard 0.0.9.0

Это краткое руководство к текущему выпуску. Подробности находятся в [README.md](README.md) и [CHANGELOG.md](CHANGELOG.md).

**Версия 0.0.9.0** добавляет поиск обновлений через Microsoft Update Catalog и интерактивную проверку загрузки ISO в Hyper-V. Возможности обслуживания языка, WIM/SWM, Windows Setup и WinRE из предыдущего выпуска сохранены.

## Скачать и запустить

1. [Скачайте LocaLizard.exe](https://github.com/lizardiot/LocaLizard/releases/download/0.0.9.0/LocaLizard.exe).
2. Запустите его и подтвердите запрос прав администратора Windows.
3. Выберите исходный ISO, выходной ISO и рабочую папку.
4. При необходимости укажите русский ISO-источник, FOD/L&O и каталог обновлений.
5. Нажмите «Проверить условия и создать ISO».

Python и инструменты разработки устанавливать вручную не нужно. Программа сохраняет исходный ISO неизменным и создаёт журнал и JSON-аудит.

## Что нового в 0.0.9.0

### Microsoft Update Catalog
- Можно указать конкретный KB или автоматически найти стабильный LCU по сборке и архитектуре выбранного ISO.
- Результаты отображаются перед загрузкой; выбранное обновление необходимо подтвердить.
- Preview/Insider/Canary, Windows Server и несовпадающая архитектура отфильтровываются.
- Используются доверенные HTTPS-домены Microsoft Update. Когда Catalog публикует SHA-1, программа сверяет его; дополнительно рассчитываются SHA-256.
- Формируются `updates.json`, `catalog-source.json` и `SHA256.txt`, а каталог цепочки автоматически указывается в настройках.
- Если Catalog возвращает неоднозначные данные или меняет структуру страницы, программа должна остановить автоматическую подготовку, а не угадывать нужный файл.

### Интерактивная проверка Hyper-V
- Опционально запускается временная VM без сети и открывается VMConnect.
- Пользователь подтверждает, виден ли экран Windows Setup. Результат записывается в JSON-аудит, после чего программа пытается удалить временную VM.
- Нужны Windows, Hyper-V и права администратора; реальная VM не запускается в GitHub CI.

## Возможности обслуживания

- Поиск подходящего Client Language Pack ru-RU в совместимом русском ISO, кэше или через UUP Dump API.
- Настройка языка, локали и клавиатуры через DISM, установка доступных языковых компонентов из FOD/L&O.
- Обработка Windows Setup `boot.wim` index 2, WinPE index 1 и вложенного WinRE, если соответствующие компоненты доступны.
- Генерация `lang.ini` и импорт подходящих Setup resources.
- Явная цепочка обновлений с `updates.json`, SHA-256, checkpoint MSU и target LCU; повторное применение LCU после языковых компонентов.
- Поддержка split-WIM `.swm`, разбиение WIM на SWM для FAT32 и режим обслуживания существующего WIM в новый файл.
- Проверка структуры результата, журнал и `.localization-audit.json`.

## Ограничения

Автопоиск LCU покрывает известные семейства сборок; для старых или нестандартных версий укажите KB вручную. Локализация WinRE и языковых возможностей зависит от соответствующего репозитория FOD/L&O. Hyper-V тест требует визуального подтверждения пользователя. Перед рабочим развёртыванием проверьте ISO на отдельной тестовой системе.

## История версий

### 0.0.8.9 — предыдущий выпуск

- Повышена устойчивость загрузок: добавлены повторные запросы, возобновление файлов и проверка перенаправленного URL.
- Управляемый кэш проверяется по размеру и SHA-256; сортировка сборок числовая, архитектура определяется строго.
- При отказе DISM проверяется следующий кандидат Client Language Pack; Server/Setup/WinPE CAB не используются как базовый LP.
- Добавлены локализация Setup/WinPE и попытка обработки WinRE при наличии ресурсов, генерация `lang.ini`, работа со SWM и обслуживание существующего WIM.
- Цепочку обновлений в этой версии нужно было подготовить заранее. Автоматический поиск LCU через Catalog и интерактивное подтверждение экрана Setup в Hyper-V появились только в 0.0.9.0.
