# LocaLizard 0.0.9.2

Это руководство к текущему выпуску. Полная история изменений репозитория находится в [CHANGELOG.md](CHANGELOG.md); страница релиза содержит отдельный журнал именно своей версии.

## Скачать и запустить

1. [Скачайте LocaLizard.exe — версия 0.0.9.2](https://github.com/lizardiot/LocaLizard/releases/download/0.0.9.2/LocaLizard.exe).
2. Запустите программу и подтвердите запрос прав администратора Windows.
3. Выберите исходный ISO, выходной ISO и рабочую папку.
4. При необходимости задайте русский ISO-источник, FOD/Language and Optional Features и каталог обновлений.
5. Нажмите «Проверить условия и создать ISO».

Python и инструменты разработки устанавливать вручную не нужно. Исходный ISO остаётся без изменений.

## Исправлено в версии 0.0.9.2

Все команды монтирования явно указывают `StorageType ISO`. При HRESULT `0xC03A0014` приложение объясняет, что Windows не нашла компонент Virtual Disk provider; очистка не пытается обрабатывать неподключённый ISO.

## Исправлено в версии 0.0.9.1

Установщик ADK всегда обновляется с официального адреса Microsoft; после ошибки проверки хеша выполняется одна повторная попытка. При очистке исходного ISO отмонтирование выполняется только для подключённого образа.

## Возможности версии 0.0.9

- Поиск определённого KB или стабильного накопительного обновления (LCU) через Microsoft Update Catalog.
- Фильтрация Preview/Insider/Canary, Windows Server и несовпадающей архитектуры; пользователь проверяет результат и подтверждает загрузку.
- Загрузка только с доверенных HTTPS-доменов Microsoft Update, сверка опубликованного Catalog SHA-1 и расчёт SHA-256. Формируются `updates.json`, `catalog-source.json` и `SHA256.txt`.
- Подбор Client Language Pack ru-RU через совместимый русский ISO, кэш или UUP Dump API; настройка локали и языковых возможностей через DISM/FOD.
- Локализация Setup/WinPE и попытка обработки WinRE при наличии подходящих компонентов.
- Обслуживание WIM/ESD, входных split-WIM `.swm`, разбиение WIM на SWM для FAT32 и обработка существующего WIM в отдельный выходной файл.
- Статическая проверка образа, журнал и JSON-аудит.
- Необязательная интерактивная Hyper-V проверка с VMConnect и визуальным подтверждением экрана Windows Setup.

## Ограничения

Автопоиск LCU охватывает известные семейства сборок; для старых или нестандартных версий может потребоваться указать KB вручную. Совместимость языковых пакетов окончательно проверяется DISM. Полнота FOD и локализация WinRE зависят от источников. Hyper-V тест требует Windows, Hyper-V, прав администратора и участия пользователя.

## История версий

### [0.0.9.2](https://github.com/lizardiot/LocaLizard/releases/tag/0.0.9.2)
Исправлено монтирование ISO и добавлена диагностика ошибки Windows Virtual Disk provider.

### [0.0.9.1](https://github.com/lizardiot/LocaLizard/releases/tag/0.0.9.1)
Исправлена установка ADK при ошибке проверки хеша `0x80091007`; актуализированы ссылки на установщики Microsoft.

### [0.0.9](https://github.com/lizardiot/LocaLizard/releases/tag/0.0.9)
Добавлен поиск и подготовка накопительных обновлений через Microsoft Update Catalog и интерактивная Hyper-V проверка.

### [0.0.8.9](https://github.com/lizardiot/LocaLizard/releases/tag/0.0.8.9)
Добавлены манифест кэша, цепочки обновлений, обработка Setup/WinPE/WinRE при наличии совместимых ресурсов, поддержка SWM и обслуживание существующего WIM.

### [0.0.8.1](https://github.com/lizardiot/LocaLizard/releases/tag/0.0.8.1) — предыдущий выпуск
Улучшены подбор и фильтрация кандидатов UUP по ветке и архитектуре, повторные и возобновляемые загрузки, проверка целостности управляемого кэша, диагностика DISM и предварительная проверка условий обработки ISO.

### [0.0.2](https://github.com/lizardiot/LocaLizard/releases/tag/0.0.2) — исторический выпуск
Добавлен дополнительный русский ISO-источник для поиска и копирования отдельных CAB языкового пакета, FOD и компонентов Setup/WinPE. Целевой ISO проверяется отдельно, образ из дополнительного ISO не подменяет целевой IoT-образ.

### [0.0.1.9](https://github.com/lizardiot/LocaLizard/releases/tag/0.0.1.9) — исторический выпуск
Улучшен поиск базового Client Language Pack ru-RU: разрешены распространённые варианты имени CAB без строгого совпадения названия редакции; архитектура и подходящая ветка Windows по-прежнему проверяются.

### [0.0.1.8](https://github.com/lizardiot/LocaLizard/releases/tag/0.0.1.8) — первый выпуск под именем LocaLizard
Проект переименован в LocaLizard; добавлены Windows GUI, выбор ISO, базовая проверка структуры, журнал и JSON-отчёт, поиск ru-RU пакетов через UUP Dump API и CI-сборка автономного Windows x64 EXE.
