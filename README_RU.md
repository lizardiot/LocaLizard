# LocaLizard 0.0.9.0

Это русскоязычное краткое руководство. Подробное описание и список изменений находятся в [README.md](README.md) и [CHANGELOG.md](CHANGELOG.md).

В версии **0.0.9.0** добавлены поиск и подготовка цепочки обновлений через Microsoft Update Catalog, проверка опубликованных контрольных сумм, создание `updates.json` и интерактивная проверка загрузки ISO в Hyper-V. Также сохранены возможности предыдущих версий — подбор языковых пакетов, обслуживание WIM/WinRE и работа с SWM.

Русский язык, уже встроенный в `install.wim`/`install.esd`, не гарантирует наличия отдельного Client Language Pack CAB. Обычный Setup-файл `sources\\langpacks\\ru-ru\\lp.cab` не подменяет базовый клиентский языковой пакет. Если standalone CAB не найден, программа продолжает прежний поиск через UUP Dump и сообщает об ограничении, а не извлекает неполный пакет вручную.

Предыдущие релизы, включая **0.0.1.9** и **0.0.1.8**, сохраняются.

## Запуск
1. Скачайте `LocaLizard.exe` из [последнего релиза](https://github.com/lizardiot/LocaLizard/releases/latest).
2. Запустите EXE и подтвердите запрос прав администратора Windows.
3. Выберите исходный ISO, выходной ISO и рабочую папку.
4. Нажмите «Проверить условия и создать ISO».

Python, PyInstaller и средства разработки устанавливать вручную не нужно. Программа сохраняет исходный ISO неизменным, ведёт журнал и выполняет статические проверки итогового ISO. Дополнительно можно запустить интерактивный тест загрузки в Hyper-V.

## Ограничения
Полная локализация речи/OCR/FOD зависит от совместимого репозитория Language and Optional Features. Автопоиск LCU охватывает известные семейства сборок; для старых или нестандартных выпусков может потребоваться указать KB вручную. Hyper-V проверка требует Windows, Hyper-V, прав администратора и визуального подтверждения экрана Setup. Перед рабочим развёртыванием проверьте ISO на отдельной тестовой системе.


## История: дополнительные возможности 0.0.8.9
- Загрузка с повторными попытками и продолжением файла; проверка перенаправленного URL.
- Манифест кэша SHA-256/размера; сортировка версий численно; строгая архитектура.
- Повторный кандидат Client LP при отказе DISM; FOD capabilities устанавливаются через Add-Capability.
- Прямой выбор ISO Language and Optional Features, предварительный план/проверка источников и сохранение путей.
- После сборки создаётся .localization-audit.json.

Оговорки в этом историческом разделе относятся к версии 0.0.8.9. В 0.0.9.0 добавлены поддержка Setup/WinPE и WinRE, поиск LCU через Microsoft Update Catalog и интерактивная Hyper-V проверка.


## История: новые функции 0.0.8.9
- Локализация boot.wim index 1 и 2, официальный WinPE Add-on, языковые Setup resources, создание lang.ini и выбор русского Setup UI.
- Обработка вложенного WinRE из L&O ISO. В WinRE используются соответствующие необязательные компоненты из L&O, а не ADK.
- Update-chain с обязательным updates.json: build, architecture, checkpoint MSU, последний target LCU, SHA-256; LCU повторно применяется после языка. Для WinRE допускаются winre_ssu и safeos_dynamic_update.
- Импорт split-WIM SWM в рабочий WIM; опциональный экспорт WIM в SWM-части по 3800 MiB.
- Кнопка обработки существующего WIM в новый файл и опциональный Hyper-V smoke-test без сети.

В версии 0.0.8.9 автоматический выбор и скачивание цепочки CU из Microsoft Update Catalog ещё не входили в программу. Эта возможность добавлена в 0.0.9.0; Hyper-V smoke-test просит пользователя визуально подтвердить экран Setup.


## Версия 0.0.9.0
- **Microsoft Update Catalog:** поиск конкретного KB или автопоиск стабильного LCU по выбранному ISO; выбор результата, подтверждение перед загрузкой, фильтр по архитектуре и стабильному каналу.
- **Обновления:** загрузка MSU checkpoint-пакетов и target LCU с официальных HTTPS-доменов; проверка Catalog SHA-1, если он доступен; локальный SHA-256; генерация updates.json, catalog-source.json и SHA256.txt.
- **Hyper-V:** приложение открывает временную VM без сети и просит подтвердить, что виден экран Windows Setup. Ответ записывается в JSON-аудит; временная VM удаляется.
- Если структура страниц Microsoft меняется или список пакетов неоднозначен, автоматическая загрузка прекращается с ошибкой вместо выбора случайного файла. VM-тест требует Windows, Hyper-V, прав администратора и ручного подтверждения.
