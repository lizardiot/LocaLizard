# LocaLizard 0.0.1.8

Это русскоязычная копия README проекта. Основная документация находится в [README.md](README.md), список изменений — в [CHANGELOG.md](CHANGELOG.md).

LocaLizard — графическая утилита для подготовки установочного ISO Windows IoT Enterprise LTSC с русским языком по умолчанию.

## Запуск
1. Скачайте `LocaLizard.exe` из [последнего релиза](https://github.com/lizardiot/LocaLizard/releases/latest).
2. Запустите EXE и подтвердите запрос прав администратора Windows.
3. Выберите исходный ISO, выходной ISO и рабочую папку.
4. Нажмите «Проверить условия и создать ISO».

Python, PyInstaller и средства разработки устанавливать вручную не нужно. Исходный ISO не изменяется. Программа сохраняет журнал ошибок, рассчитывает свободное место и выполняет статические проверки итогового ISO.

## Ограничения
Это ранняя версия 0.0.1.8. Полная локализация всех речевых/OCR/FOD-компонентов не гарантируется и зависит от версии и архитектуры исходного ISO. WinRE отдельно не модифицируется; Setup/WinPE зависит от подходящих компонентов ADK. Тест загрузки в виртуальной машине не выполняется. Проверяйте выходной ISO на тестовой системе прежде, чем использовать его в рабочей среде.
